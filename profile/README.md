Badilk answers one hard question in the spare-parts market: **does this part actually fit this phone?** Buyers and repair shops usually rely on guesswork, and mistakes cost money. Badilk replaces that with a comprehensive compatibility platform kept current by an automated data-discovery engine.

### 📊 At a glance

- **2,500+** phone models in the catalogue
- **36,000+** phone-and-component compatibility records
- Holds the official **Innovative Project Label** from the Algerian Ministry of Knowledge Economy, Startups and Micro-enterprises

### 🧩 The platform

- **Badilk app** — search any phone and find the spare parts that fit it · [Google Play](https://play.google.com/store/apps/details?id=com.haithem.apps.badilk)
- **Badilk Studio** — internal app where our team maintains the phone and parts data
- **Badilk Ops** — operations dashboard (Next.js + Supabase)
- **Website** — [badilk.com](https://badilk.com)

### 🛠️ Tech

`.NET 8 / ASP.NET Core` · `Clean Architecture` · `PostgreSQL` · `Redis` · `Flutter` · `Nginx` · `GitHub Actions`

The backend is built on Clean Architecture, with an automated data-discovery engine (rate limiting, proxy pooling, header randomization, caching, incremental discovery, and a circuit breaker) that keeps the catalogue fresh without manual entry.
